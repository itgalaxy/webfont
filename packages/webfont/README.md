# webfont

Generator of fonts from SVG icons; decompress WOFF/WOFF2 to embedded TTF/OTF (not TTF↔OTF transcoding).

- **Documentation:** [webfont.js.org](https://webfont.js.org) (or the [repository README](https://github.com/itgalaxy/webfont#readme))
- **npm:** [webfont](https://www.npmjs.com/package/webfont)
- **Issues:** [github.com/itgalaxy/webfont/issues](https://github.com/itgalaxy/webfont/issues)

This directory is the published npm package (`name: "webfont"`). The monorepo root holds the VitePress docs site and shared tooling.
